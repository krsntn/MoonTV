# krsnTV

krsnTV is a video browsing and playback app. It shows titles from a Catalog and plays them from Sources.

## Language

### Browsing

**Channel**:
One content type that a viewer can browse: 电影, 电视剧, 综艺, or 动漫.
_Avoid_: type, category, section

**Channel page**:
The entry view of a Channel, which shows a few rows of titles that each lead to a filtered Listing.
_Avoid_: channel home, category page

**Shelf**:
A titled row of titles on the home page or a Channel page that leads to a filtered Listing.
_Avoid_: row, rail, section

**Listing**:
The browse view of one Channel, which shows titles that match the selected filters.
_Avoid_: douban page, browse page, list

**Result page**:
One numbered page of a Listing.
_Avoid_: page (alone), page 2

### Content

**Catalog**:
The provider of the titles that a Listing shows. Today the Catalogs are Douban and Bangumi.
_Avoid_: data source, douban (as a general term)

**Source**:
One video resource site that supplies playable episodes for a title.
_Avoid_: API site, 资源站, provider
